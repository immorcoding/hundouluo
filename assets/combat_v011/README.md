# #26 · 战斗视觉候选 / 等待用户审阅

本目录为 Astra 设计、Codex 内置 ImageGen 生成辅助的原创战斗美术；不是手绘或第三方素材包。未接入正式场景。

## 来源和重建

- 原图 `source.png`：1254×1254 RGBA，内置 ImageGen 输出 `exec-3e1b2f15-2de6-4cf3-991c-92c3b7fc45c7`，2026-09-29。实际输出尺寸与请求的 1024×1024 不同，构建使用实际尺寸。
- 完整生成提示词见 `PROMPT.txt`。没有输入第三方图像；#22 已确认机库截图只由设计代理查看以核对风格。
- 本票新增原创源图、图集和工具随仓库 MIT LICENSE 分发；预览中的机库与角色来自本仓库 #22，既有来源见 `assets/art_source/README.md`。无新增第三方资产。
- 从项目根执行 `Godot_v4.7.2-stable_win64_console.exe --headless --path . --script assets/combat_v011/build.gd`。
- Godot 做格提取、按每行共同边界缩放、最近邻采样和装配。前七行使用等分格；最后一行按实际源图改从 y=1040 提取，覆盖完整充能环（实体 y=1063..1206），避免旧等分起点 y=1092 截断顶部。alpha < 0.3 的边缘仅不参与测量；裁切内原 alpha 保留。不重新请求模型，结果可离线重建。
- 原始源图是位图，不是分层绘画工程。生成模型的四帧轮廓略有差异，需真人审阅。

## 帧契约

`atlas.png` 为 192×320，4 列 × 8 行，固定 48×40 单元。每格中心 pivot=(24,20)，最近邻，无 mipmap；`atlas.json` 给出每行索引和占用上限。透明边不代表碰撞尺寸。帧索引从 0 开始，以下行号也从 0 开始。

| 行 | 名称 | 形状 / 方向 | 建议时序 |
|---|---|---|---|
| 0 | friendly | 青白圆头短弹，向右 | 4 帧循环，每帧 50 ms；反向使用水平翻转 |
| 1 | soldier | 橙红尖头实体弹，向左 | 4 帧循环，每帧约 83 ms |
| 2 | mech | 更宽双层尖角弹，向左 | 4 帧循环，每帧约 83 ms；三发低弹道，间隔 220 ms |
| 3 | friendly_muzzle | 青白枪口，向右 | 点火→扩张→收束→余迹，各 50 ms，播放一次 |
| 4 | enemy_muzzle | 橙红枪口，向左 | 同上，各 50 ms，播放一次 |
| 5 | armor_hit | 青金火花、金属碎片 | 4 帧 200 ms，播放一次 |
| 6 | wall_hit | 低亮金灰碎屑 | 4 帧 200 ms，播放一次 |
| 7 | mech_charge | 空心分段环，逐渐增大 | 4 帧各 250 ms，共 1 s；中断立即移除，不循环闪烁 |

弹丸以轮廓与大小辅助颜色识别；机甲弹道位于地面上方 18 像素。亮光局限于局部小精灵，无全屏闪白、震屏或音轨。正式接入时沿用原弹丸速度、伤害、碰撞层、信号和蓄力时长，表中展示时序不构成玩法修改。原 `CombatFeedback` 命中时长为 160 ms，工程接入可将四帧映射为各 40 ms 以保留该契约。
