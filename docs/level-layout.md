# #16 五段关卡布局与集成接缝

基线：`origin/main` 的 `c1e9c85`；范围只含关卡、镜头和唯一缺口。
640×360 逻辑视口与 #22 的 1440×360 远／中景、1440×108 甲板、24px 黄色警戒图块继续使用原始分层资源；每 1440px 重复一段，不拉伸素材。
地面碰撞矩形是甲板裁切和缺口边缘的唯一坐标来源。

| 阶段 | 水平范围（px） | 可玩节奏 |
| --- | ---: | --- |
| 1 安全跑跳 | 0–600 | 起点 x=140，平地学习跑跳与射击；首兵初始不完整入镜。 |
| 2 单兵 | 600–1120 | 单兵中心 x=810，可打或跳过；与缺口留有隔离距离。 |

| 4 组合挑战 | 1760–3500 | 两组机械兵在 x=1940/2180 与 2920/3160，组间留空；640px 镜头里最多两名。无第二个缺口。 |

行动员当前 `run_speed=210`、`jump_speed=360`、`gravity=900`。同高抛物线估算腾空 0.8s、水平约 168px；96px 缺口约为估算跳距的 57%。自动输入从 x=1305 跳跃并持续向右，能在对岸落地；这是工程检查，不是可靠手感的真人确认。左沿前 334px（玩家 x≈1010）两侧已同时进入镜头；起跳区域平坦，没有临边额外敌人。跌落 y≥410 时将行动员生命置零、发出其 `health_changed(0)` 和 `died()`，关卡另发一次 `operative_fell` 以标识死因，等待 #18 接死亡界面和完整重试。没有检查点。

镜头 y=180 固定，水平跟随为行动员 x+115，并限制中心 x 在 [320,4000]；视口前方约 435px。关卡只在机械兵完整处于实际视口后启用攻击；机械兵自身预告时间仍由其场景参数控制。敌我弹继续共用 `Projectiles` 容器，关卡连接五名机械兵的 `projectile_fired`，不改动 #15 模块。

#17 可直接在 `BossSlot` 下实例化防御机甲并接其弹丸信号；#18 可订阅行动员 `died`、`health_changed` 与关卡 `operative_fell`。`ExitDoor/DoorBlocker` 阻止尚无通关逻辑时跑出地图；机甲击败后的开门／通关可禁用这个门挡，由后续票据实现。未接入防御机甲、HUD、死亡菜单或通关条件。

待真人试玩记录：实际多次起跳的可靠距离与时机、缺口是否宽窄合适、镜头前导量／停止位置、两组战斗间距以及首次通关总耗时。3–5 分钟是完整原型的试玩目标，不由本关卡自动测试证明；后续反馈可直接调场景碰撞矩形、敌人位置和关卡镜头常量。
