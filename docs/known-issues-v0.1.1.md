# v0.1.1-rc.1 已知事项

工程完成与用户接受分开记录。最终严格测试和实机证据见 `docs/art/issue-31/`；候选构建提交在 ZIP 的 `BUILD_INFO.txt`，并以交付校验清单为准。

| 项目 | 当前边界 | 验收判断 |
| --- | --- | --- |
| 整关像素统一 | 旧背景/角色细密纹理与门框/短动效硬边密度仍有差异；局部美术批准不等于全局通过 | 用户按实机图和运动决定是否有界返工 |
| S6缺口遮挡 | 左下192×68 HUD遮缺口下部及部分竖向警戒边；顶部开口和地面边缘仍可见，沿用获批布局 | 用户确认取舍可接受；不自行改布局 |
| 墙式门结构 | 双侧下部框为后景装饰，未新增宽实体侧墙；上部甲板纹理较密、下框较平整 | 用户判断墙门读数与风格 |
| 门安全余量 | x3396止退约3415.075，原420px射程余量约5.075px；固定x3580机甲右边余量6px | 已有实际敌我命中回归；以后改锚点/门位需重验，禁止盲目再左移 |
| 机甲战30–45秒 | 42HP旧命中率模型推算42秒，但合法自动策略真实弹丸通关约7.27秒，低于目标；不能替代真人首次成功 | 本候选不擅改数值，用户填真人时间/手感并决定是否调参 |
| 枪口/低弹道空间差异 | 机械兵实际发弹仍比#26高枪口摆拍低约19px；机甲环/三弹仍在低位，没有高炮口转场 | 保留已合并#29规则，用户看实机决定是否另作有界设计 |
| 声音与按键组合 | 音效接线/音量级与输入分离可自动验证；设备听感和键盘ghosting未由真人验证 | 用户在自己的设备有声/静音检查 |

上述是披露的验收项，当前不宣称其全部接受。工程诊断若出现、包无法启动、无法完成或R无法复位、单方面安全点/屏外未预告伤害为阻塞，不发布正式版本。BGM、主菜单/设置、多关、新敌人及动作扩展延期。
