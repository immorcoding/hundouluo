## 独立原始素材与可切片信息

- `source/console-panel.png`：内置 ImageGen 原始 RGBA PNG，1774×887。提示词与输出标识见 [PROMPT.md](source/PROMPT.md)，无需生成缓存即可重建。
- 面板源区域 `[20,92,1734,682]`（不透明主体约 `[25,97,1724,672]`）。Godot 仅按区域采样，不改原 PNG；最终显示 348×174，边框纵向有适配缩放，最近邻过滤。
- 若工程改用 NinePatch：以该源区域为纹理区域，建议左/右 150、上/下 100 源像素为边界保留区，内侧可延展；接入时须重新审看角部与细线。当前评审是整区缩放，NinePatch 参数为交接建议，并非已验证运行资源。
- 生命格、底板、刻度、键帽、文字均在 `render_previews.gd` 中以 Godot 原生可编辑绘制，避免把数字和中文烘进位图。HUD 不需要切片图集。
- 预览文字使用 Windows `Microsoft YaHei` SystemFont（字重请求 600）；未复制或分发字体文件。其他系统可能回退，精确复现需同字体；正式跨平台入包字体应在接入票中确定授权来源。当前没有新增可执行包内字体。

## 复现

在指定 worktree 根目录运行（Godot 4.7.2，Windows 图形会话）：

```powershell
& Godot_v4.7.2-stable_win64_console.exe --headless --editor --path . --import
& Godot_v4.7.2-stable_win64_console.exe --path . --rendering-method gl_compatibility --script prototypes/issue-27-ui/render_previews.gd
```

渲染工具只写本目录 captures/ 与 previews/。首次 Godot 导入会产生缓存和导入元数据；它们不是本票交付。原始场景可单独 F5 运行，仍是原 UI。
